# 🎖️ Military Shift Automation Bot

A Telegram bot designed to automate and simplify the management of military shift requests and assignments.

The project was developed to practice **backend development, database management, business logic, and process automation** using Python and MySQL.

## 🎯 Project Goal

The main goal of this project is to replace manual shift management with an automated system where soldiers can submit their requests and administrators can manage, review, and assign shifts efficiently.

## ✨ Features

* 👤 Soldier panel
* 🛠️ Admin panel
* 📋 Submit and manage shift requests
* 🔎 Filter requests based on soldier attributes and rank
* 📅 Manage and assign shifts
* 🔄 Automated shift management workflow
* 🗃️ Persistent data storage using MySQL
* ⚙️ Rule-based processing of shift requests
* 🔐 Separate access and functionality for soldiers and administrators

## 🧠 Core Logic

The bot handles the shift management process through a structured workflow:

**Soldier → Shift Request → Request Processing → Admin Management → Shift Assignment**

Requests can be processed according to predefined conditions such as the soldier's **rank and other attributes**, making the assignment process more organized and less dependent on manual operations.
